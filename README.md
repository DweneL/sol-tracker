# Sòl Tracker

**Kreyòl:** Yon ti zouti pou swiv yon sòl: kiyès ki peye, kiyès ki gen men an, ak ki lè pwochen tou a ye. Li pa kenbe lajan, li jis ede w swiv.

**English:** A simple tool to keep track of a sòl (Haitian rotating savings group): who has paid, who gets the payout (*men*) this round, and when the next round is. It never holds money; it only keeps track.

## Status
🚧 In progress. Built step by step as a learning project.
